# PortScope 二次开发修改记录

## 2.2.0 · 2026-11-16

本版本基于电导实验室（Conductance-lab）开发的 SerialWeb 2.1，使用产品名称「澄波 PortScope」。它是二次开发版本，并非原作者发布的版本。

- 重新设计产品标识、页面标题、顶部导航、浅色 / 深色配色、面板与关于页，采用青绿色与石墨灰的串口工作台视觉。
- 移除界面中的原作者推广、B 站、官网、GitHub、工具手册与问题反馈入口，移除跳转原在线版的交互和页面访问统计请求。
- 关于页保留简洁的原项目作者归属、许可及修改信息，不再展示推广链接。
- 保存 HTML / 源码入口使用当前部署文件；本地打开时提示通过浏览器另存为保存。
- 保留串口连接与收发、文本 / HEX 解析、图表、时间线及配置格式和存储键，便于继续使用原有配置。
- 原始 `LICENSE` 原样保留，已有源码版权与出处声明保留，继续采用 AGPL-3.0。发布的 `index.html` 即完整可读应用源码；本记录与许可证随包分发。

验证：提示词同步、既有时间基准回归、Chromium 浏览器解析与界面检查。实体串口和下游设备行为不在本次验证范围内。具体执行结果见本地 `artifacts/portscope-browser-result.json`。
